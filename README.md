# AeroFit AR (แอร์โรฟิต เออาร์)
**แอปพลิเคชันเกมความเป็นจริงเสริมเพื่อยกระดับคุณภาพการออกกำลังกายแบบบอดี้เวทด้วยเทคโนโลยี MediaPipe**

> โครงร่างปัญหาพิเศษ สาขาวิชาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏพิบูลสงคราม  
> ผู้วิจัย: นายยศสรัล มั่นมุ่งยนต์ (รหัสประจำตัว 6612231065)  
> อาจารย์ที่ปรึกษา: ผศ.ดร.ปาณิสรา หาดขุนทด

---

## 📌 จุดเด่นของระบบตามโครงร่างวิจัย

1. **MediaPipe Pose Landmarker (Google):** ตรวจจับและสกัดพิกัดจุดสำคัญของร่างกาย 33 จุด (3D World Coordinates) แบบ Real-time ผ่านกล้องเว็บแคม/สมาร์ตโฟน
2. **การคำนวณองศาข้อต่อด้วยตรีโกณมิติ (Trigonometry):** ประมวลผลรวดเร็ว ไม่กินทรัพยากรสูง ตรวจจับมุมเข่า สะโพก และการหมุนตัว
3. **ปรับเกณฑ์มุมข้อต่อตามค่า BMI (ตารางที่ 5.1):**
   - **Squat (สควอท):** 
     - BMI < 23.0: งอเข่า 80° - 100°
     - BMI 23.0 - 29.9: งอเข่า 50° - 70°
     - BMI ≥ 30.0: ย่อตื้น 35° - 50°
   - **Side Lunge (ก้าวข้างย่อเข่า):**
     - BMI < 23.0: งอเข่าข้างรับน้ำหนัก 70° - 90°
     - BMI 23.0 - 29.9: งอเข่า 50° - 70°
     - BMI ≥ 30.0: ก้าวสั้น งอเข่า 30° - 50°
   - **Standing Cross Crunch (ยืนครันช์สลับ):**
     - BMI < 23.0: ยกเข่างอสะโพก 60° - 80°, หมุนลำตัว 20° - 30°
     - BMI 23.0 - 29.9: ยกเข่า 45° - 65°, หมุนลำตัว 15° - 25°
     - BMI ≥ 30.0: ยกเข่า 30° - 50°, หมุนลำตัว 10° - 20°
4. **กลไกความเป็นจริงเสริมและเกมมิฟิเคชัน (AR Gamification):**
   - แสดงไอเทม AR (ดาว, เพชร, หัวใจ) ลอยบนหน้าจอ เก็บสะสมแต้มเมื่อทำท่าถูกเกณฑ์
   - ระบบนับรอบอัตโนมัติ (Rep Counter) และระบบคอมโบ (Combo System)
   - แถบความถูกต้องแบบเรียลไทม์ พร้อมคำแนะนำจากโค้ช AI
   - ระบบเสียงสังเคราะห์ด้วย Web Audio API (นับถอยหลัง, เสียงเหรียญ, เสียงคอมโบ, เสียงจบเซ็ต)
5. **แบบประเมินความพึงพอใจ 5 ระดับ (Likert Scale) พร้อมคำนวณสถิติ:**
   - ประเมิน 3 ด้าน (การออกแบบ UI, ประสิทธิภาพ MediaPipe/AR, ความพึงพอใจภาพรวม)
   - คำนวณค่าเฉลี่ย (Mean) และส่วนเบี่ยงเบนมาตรฐาน (S.D.) เพื่อตอบสมมติฐานวิจัยข้อ 4.1

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd aerofit-ar

# 2. ติดตั้ง Dependencies (ทำไว้เรียบร้อยแล้ว)
npm install

# 3. รัน Dev Server
npm run dev

# 4. บิลด์สำหรับ Production
npm run build
```

เปิดบราวเซอร์ไปที่ `http://localhost:5173` เพื่อเริ่มใช้งาน!
